# [Justify Grid](http://justifygrid.com/)

Justify Grid is a new way to create layouts featuring `text-align: justify` and
`inline-block`.

It's not a real framework but rather a methodology. To read more about that go
to project's home page: [http://justifygrid.com/](http://justifygrid.com/)
This project on GitHub is to mostly about the Sass helpers and contains a
pre-compiled framework to get you started.

## Website

The original justifygrid.com website is preserved in `website/`, including its
interactive CSS builder. It is plain HTML, CSS and JavaScript; no install or
build step is required. Serve that directory with any static web server.

The Vercel project `justifygrid` uses `website/` as its Root Directory, the
Other framework preset, and `.` as its Output Directory. Build and install
commands are empty. Web Analytics is enabled in Vercel and loaded using the
static-site script in `index.html`.
